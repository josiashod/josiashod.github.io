Description du projet

Simulation de connexions V2V basée sur des données géographiques OpenStreetMap pour reconstituer une carte de Mulhouse et modéliser le réseau routier.

Le projet intègre un graphe non orienté, le calcul d'itinéraires avec Dijkstra, une base SQLite et un moteur de mouvement fluide.

Technologies utilisées

C++QtSQLiteOpenStreetMapDijkstra

Compétences développées

  • Modélisation de graphe routier.
  • Lecture et traitement de données géographiques.
  • Stockage et récupération de données avec SQLite.
  • Optimisation CPU via gestion asynchrone des cycles de calcul.
  • Conception d'une simulation interactive.
